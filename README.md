# Ali.dev — پورتفولیوی علی منصوریار

یک وب‌سایت نمونه‌کار فارسی، راست‌چین و واکنش‌گرا با HTML/CSS/JavaScript ساده.

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای انتشار رایگان، GitHub Pages را از Settings → Pages روی branch `main` و پوشه `/(root)` فعال کنید.

## شخصی‌سازی
- اطلاعات معرفی: `index.html`
- ظاهر و رنگ‌ها: `style.css`
- تعاملات منو و انیمیشن‌ها: `script.js`

## قالب و محتوا
این پروژه یک طراحی مستقل و الهام‌گرفته از سبک پورتفولیوهای مدرن است؛ قالب Starfolio در این مخزن کپی نشده است.
